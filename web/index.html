Welcome to FrIDE

FrIDE has no configuration yet, so it does not know where your repositories are or how your app starts. A coding agent sets that up with you: it asks which folders to scan and which repositories are the core of your app, then works out how to install and run each one and keeps trying until the stack starts.

  1. Open a terminal in the FrIDE repository (where you built fride).
  2. Start your coding agent there — claude, codex or another.
  3. Ask it: “Set up FrIDE for me.” It follows SETUP.md.

Prefer to write it yourself? The file is ; docs/CONFIG.md describes every field.

Computers

Your computers running FrIDE, linked through your tailnet. Each one owns its tasks; this page, the board and every task view work the same from any of them. Only devices signed in to your own account are answered.

Port slots

Each running task holds a slot k, and every per-task port is the service’s base port + k — so tasks never collide with each other, and slot 0 (the base ports themselves) is left to your main checkouts.
